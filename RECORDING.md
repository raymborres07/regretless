# Regretless — 2:30 recording plan

## Before you hit record

Open the app at desktop width (1440 × 1000 or larger works well), dismiss notifications, and click **Recording desk** in the top bar. Rehearse with **Show narration notes**, then hide notes for the take. Use **Next chapter** at your pace. **Restart walkthrough** only returns to chapter one; it does not reset or delete purchases.

This zero-credit walkthrough uses existing seeded purchases and a real Convex subscription. Replay events are simulated and labeled. Do not describe the recording as proof of live OpenAI extraction, an AgentMail send, or a real refund.

## Script

**0:00–0:20 · Dashboard / hook**

“Cashback apps stop working when you hit Buy. Regretless starts working. It is a post-purchase agent that watches prices and policies, finds potential recoveries, and helps you ask for your money back. These dashboard totals are examples, not actual recovered funds.”

**0:20–0:45 · Chapter 1 / receipt**

“Here is a fictional $449 headphone purchase. A receipt becomes a case: the product, original price, order number and purchase date are stored in Convex. In the live integration, OpenAI extracts those fields and the user confirms them.”

**0:45–1:10 · Chapter 2 / price drop**

Click **Replay Convex timeline** and let the status progress.

“The listed example price is now $399. That is fifty dollars most people never notice. This scenario replay is simulated, but these status changes really are stored in Convex and pushed to this screen in realtime.”

**1:10–1:35 · Chapter 3 / policy**

“A lower price is not enough. The agent checks the exact item and the adjustment window, with quoted evidence. Firecrawl has successfully retrieved these public, fictional test pages. For real purchases, uncertain policy evidence requires manual review. We never promise a refund.”

**1:35–2:00 · Chapter 4 / approval**

“The next step is a concise, editable request. Sending requires the user's approval. The AgentMail send-and-reply integration is implemented, but this example is not sent. Live OpenAI and email execution still need account credentials.”

**2:00–2:30 · Chapter 5 / vision**

“Price drops are only the beginning. Imagine the same agent watching missed promotions, delivery guarantees and return deadlines. Normally, a price drop after you buy is regret. We turn it into a claim. Regretless: your purchase does not stop working for you after checkout.”

## Budget and submission caveat

The recording desk needs no paid OpenAI or AgentMail credits. It is a product walkthrough, not a verified full sponsor-API demonstration. The original requirement for meaningful live OpenAI and AgentMail work remains unfinished. Ask the hackathon organizers about sponsor credits before submission; do not assume they are available.

AgentMail currently advertises a free tier with three inboxes and 3,000 emails per month, with no credit card required: https://www.agentmail.to/pricing . A free account still needs an API key. OpenAI calls need a funded API account or applicable granted credits; this app does not use the Codex chat session as an API proxy.
